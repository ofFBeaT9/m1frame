# Headroom

Headroom provides an optional Python `compress(messages, model=...)` API that
returns compressed messages and token metrics. The library supports Python 3.10+
and documents a live-zone, reversible context-compression pipeline.

Source: https://github.com/headroomlabs-ai/headroom
