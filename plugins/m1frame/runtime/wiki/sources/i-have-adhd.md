# i-have-adhd

The upstream skill defines ten response-shaping rules: lead with the next action,
number multi-step work, suppress tangents, restate state, use concrete time
estimates, make wins visible, state errors matter-of-factly, cap lists, and avoid
prefaces or closers. It is a prompt skill rather than a Python runtime library.
