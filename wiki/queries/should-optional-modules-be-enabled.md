# Should Optional Modules Be Enabled

**Answer:** Enable ADHD shaping for user-facing deployments that prioritize
actionable prose. Enable Headroom only after installing and measuring
`headroom-ai` in the target environment; its fallback is safe, but compression
cost and quality should be validated for each model and workload.

This decision follows the synthesis in [[m1frame Optional Modules]] and the
separate contracts [[ADHD-Friendly Output]] and [[Headroom Context Compression]].
