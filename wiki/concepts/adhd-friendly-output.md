# ADHD-Friendly Output

[[m1frame]] implements a conservative, opt-in form of the
[[i-have-adhd]] response contract. It adds action-first system guidance and
removes common filler preambles or closers only from final prose. Structured
JSON, YAML frontmatter, fenced code, and intermediate agent outputs are
preserved.
